SLIDE 5: SO SÁNH TRƯỚC/SAU
====================================================
Title: ⚡ Trước vs Sau

TRƯỚC:
• Developer đọc log thủ công
• Tìm file lỗi bằng kinh nghiệm
• Tự viết fix code
• Bug không được track
• Thời gian: 1-2.5 giờ
• Yêu cầu: Senior developer

SAU (AI Debugger):
• AI tự động capture log
• Tự động tạo Bug trên Backlog
• AI locate file chính xác
• AI generate & apply fix
• Mọi bug đều được track
• Thời gian: 1-3 phút
• Yêu cầu: Bất kỳ developer

====================================================
SLIDE 7: AI AGENT WORKFLOW
====================================================
Title: 🤖 Multi-Agent Pipeline

4 Agents hoạt động tuần tự:

1️⃣ AGENT ANALYZER
   • Parse error log
   • Detect language/framework (PHP, Laravel...)
   • Extract file_path, line_number
   • Read code context

2️⃣ AGENT FIXER
   • Receive analysis data
   • Read full file for context
   • Generate fix (JSON list of edits)
   • Block vendor/ modifications

3️⃣ AGENT SYNTHETIC
   • Apply fixes to files
   • Run syntax check (php -l, etc.)
   • Verify & report

4️⃣ AGENT BACKLOG (Optional)
   • Parse Backlog webhook
   • Extract error from issue description
   • Convert to standard format

SLIDE B4: Backlog Integration Flow
----------------------------------
Full Flow:
1. Laravel bắt lỗi (Exception Handler)
2. Gửi POST /analyze-error với error data
3. Python gọi create_backlog_issue()
   • Tạo Bug issue trên Backlog
   • Summary: "Auto-Bug: {error_message}"
4. Backlog gửi Webhook → /analyze-backlog
5. Check issueType == 'Bug'?
   • Không → Skip
   • Có → Tiếp tục
6. Agent Backlog parse description
   • Dùng AI extract: message, file, line, trace
7. Ingest vào Laravel (/ingest-log)
8. Chạy AI Pipeline:
   • Analyzer → Fixer → Synthetic
9. Lưu kết quả vào thread
10. Hiển thị trên Dashboard

Lợi ích:
• Mọi bug đều được track trên Backlog
• User có thể tạo bug thủ công trên Backlog
• Tránh duplicate processing

SLIDE B5: Multi-Agent Benefits
------------------------------
Tại sao Multi-Agent?
• Separation of Concerns - Mỗi agent 1 nhiệm vụ
• Specialized Models - Fixer dùng Codex, Analyzer dùng GPT
• Better Quality - Mỗi step được verify
• Easier Debug - Biết agent nào có vấn đề
• Extensible - Thêm agent mới dễ dàng

Pipeline: Error → Analyzer → Fixer → Synthetic → Result
